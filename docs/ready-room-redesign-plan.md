# R116 整备室改版方案

本文件为 2026-11-12 的初稿。最终实现与后续需求见 [0.3.76 阶段记录](RELEASE-R116-0.3.76.md)。

2026-11-12。基于本聊天的八张《少前2》整备室截图、图上批注和后续澄清。本阶段为当前工作区的方案记录和本机原包核查。

## 主界面

- 左侧人物栏可上下滚动。收起时使用默认造型的圆头像，未选中有淡边，选中有亮边和发光。展开时用浅色底的矩形头像卡，可参考图 2 的三列网格，选中用黄橙色框。同一角色的头像随角色身份固定，只有换装模型的角色也显示其默认造型头像。
- 中间保留大幅实时人物预览。背景参考图 1 的工业机库构图重做一版，让空间结构和人物轮廓更清楚。两侧界面用局部浅淡托底，给人物留出空间。
- 右侧保留半透明底和顶部角色名。以小方块组织 R116 已有功能，如胸部物理、武器校准、表情、VMD 读取。底部小图标只留衣服入口。右下大按钮用于启用当前角色并显示启用状态。左侧选人用于浏览，右下按钮才把角色应用到 PZ。
- 图中的战力、等级、技能、备勤区和数字为原游画面参考。R116 面板内容以实际功能为准。

## 人物状态

| 状态 | 左侧头像 | 选中后的中间内容 |
| --- | --- | --- |
| 未接入角色包，或角色包未启用 | 沿用现有锁定样式。头像压暗并叠锁 | 显示「该角色模组未启用，请到创意工坊订阅并启用」 |
| 角色包已载入，角色还未抽到 | 表示角色待解锁 | 参考图 8 的压暗人物和锁。单抽 ×1、十连 ×10 的入口放在中间人物下方的两个标注位置，先占位 |
| 角色已解锁 | 正常头像 | 正常预览，可从右下启用角色。是否正在启用是独立状态 |

「未载入」按最新澄清沿用简单的锁定头像与工坊提示。图 8 的人物展示及抽卡入口只对应角色包已载入、角色尚未取得的情况。图 7 提供单抽、十连和资源图标的样式参考。右上资源栏保留原图左侧的抽卡资源和最右侧的蓝色资源，两种未来均用 PZ 游戏内钞票兑换。兑换比例、抽取规则和资源扣除等后续确定。

## 换装页

- 点击衣服图标进入。中间保留人物展示，右侧换为皮肤卡片。选中卡略微放大、描边高亮，中间随之预览这套衣服。左下显示皮肤名和角色名。有官方皮肤介绍时复用，缺少介绍时省略。
- 当前穿着、已拥有可更换、未拥有是三个状态。有模型的未拥有皮肤可先预览，卡片压暗并显示锁，右下提供购买入口。购买纳入游戏内钞票这套经济，所用素材、价格和扣款细节待确定。

## 原游戏动效参考

本机原包来自 `GF2_Exilium_Data/LocalCache/Data/AssetBundles_Windows`。沿现有原始资源读取器检查 Unity 物件、材质和遮罩。

| 项目 | 本机原包读到的内容 |
| --- | --- |
| 圆头像选中效果 | `UI_ChrCardMainPanel_Round_Fx_01` 同时有网格版本和粒子版本，粒子版本下有 `Ring_01`，配置为循环。材质使用 `Mask_07` 和 `Mask_08`，`_MainTexPannerY` 为约 0.66。可参考「淡边打底，加一层沿遮罩移动的高光」 |
| 人物总览和换装卡 | 同包有 `UI_ChrCardMainPanel_Fx_01`，以及 `UI_Btn_ChrSkinChangeItem_Fx_01`、`_Fx_02`。其中 `_Fx_01` 使用 `Mask_17`。可以参考卡片描边与高光独立叠加的做法 |
| 来源与核查范围 | 上述效果物件和材质来自 `7d58164bc5d04e96657522f108e0953d.bundle`，三张遮罩来自 `17fb92e0ba8a222d87042446be449703.bundle`。另检查了已索引 UI 包中 566 个动画片段的名称，尚未定位头像栏展开、总览切换装所用的确切时间曲线或触发顺序 |

R116 的动效可以从三个可见动作起步。收起与展开时头像栏顺滑切换，当前选中始终可见。点选头像时先给清楚的选中反馈，再让边缘高光流动。进入换装时保持人物展示连贯，让右侧卡片和左下介绍过渡，选中卡轻微放大后停稳。具体速度和曲线由后续动效样稿对照实机确认。

已有原包提取记录可用于后续换装素材核对。莱娅等角色的卡面可从 `Img_ChrSkinPic_*` 定位，官方皮肤名称和介绍已在部分角色的 `ClothesData` 与简中文本表中核实。每套皮肤按其实际记录取用。
