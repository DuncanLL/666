# R116 0.3.66 黛烟单角色试验池

基于 0.3.65。未解锁的人形保留左侧头像栏与中央实时虚影，原游戏横幅、属性和定位短标签放在左下标注区，访问一次与十次移到右下。索米继续作为锁定展示，实际抽取只开放黛烟。切人时清除上一角色的旋转、缩放、上下平移及脸部聚焦，重新以新模型居中。

本机《少前2》简中公示条目 94905 说明连续 58 次未出精英后下次访问开始提升概率，80 次内必出精英。软保底幅度由 VAL13 在运行时填入，本机静态表未核到实际值。角色池基础概率 0.6%，参考 Bwiki 角色池说明。R116 测试暂用每抽加 4.5 个百分点，按这条曲线推算综合率约 1.89%。试验池只有黛烟，所以第 80 抽直接解锁。十连最多使用 10 张票，命中后结束本次访问并保留剩余票。计数与解锁保存在整备室的玩家资料内。

Kahlua 和 PZ 原生按钮处理验证了概率边界、连续 79 次未命中后的第 80 抽、十连中途命中、券数不足、关闭重开后保留解锁、切换人物的镜头状态和画面布局。游戏退出后已同步本地 MOD 与工坊作者目录，逐文件回读通过。实机画面待验收。
