## 当前 Native 原游材质接入

沿真实源预制体 `417ed7c9488f1eb3abb470df7e3be8fa.bundle` 及其 renderer、材质、纹理、程序、UV 和 bind 几何对应。增量追加 38 份被实际使用的源材质，形成 64 个源绘制部件和 103,754 条方向／属性记录，旧模型、材质及公共光影配置保持。

- 源 Blend 一个空材质槽及一个装饰贴图候选不明确。136 个三角由几何＋UV 唯一对应至原材质，位置误差小于 3.6e-6 模型单位；普通材质覆盖图也恢复为对应原底图。
- 907 个目标新增／修改面使用已有 Blender MikkTSpace 和 SmoothNormal 资料制作流程补方向，PMX 几何、UV、权重不改。其中两块各 63 面的额外后发卡没有唯一原表面，明确作为目标作者映射选择原后发材质，不声称恢复了这些面的原属性。映射依据和需目视确认的范围保存在私有阶段记录。
- 四个新增原片元变体核查其原 MRT 输出；使用原有编译／桥接方法，没有替代其光照公式。最终仅两份原程序需要新增载荷，其余复用现有资源。
- 真实绘制发现公共接入器缺少 `_FurShellFactor`。该字段按原反射为 **float4**；现有基础 GFCharForward 绘制提供 `(0,0,0,0)`，未增加 GFFurStep 多层毛绒绘制。原序列化 GFFurSurface 特征为非活动；没有实际原游运行捕获，不能宣称完整壳层效果已还原。
- 仅修改现用接入 JAR 的 `AimohGf2FrameInputs.class`，编译前与现装类字节相同；其余类、内嵌光影及各端不同版本保持。相同两行源修复已单独同步 Native 生产工作区，提交 `202dfc0`，不合入该工作区其他渲染改动。

本机 AMD、官方 VP 0.1.7-rc2、实际新人物核心与独立接入层执行 Native 绘制。Steam 接入候选完成主要 27 组合绘制，F 接入候选单独绘制通过，GL 错误为零；私有静态夹具中的物理关闭，不能冒充动态物理联绘测试。保存一张 Native 预览和一张三套普通工作台联图，没有逐动作大量渲图。
