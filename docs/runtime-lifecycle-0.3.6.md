# R116 0.3.6：切换交接、配置提交与资源收尾

状态：独立候选和针对性组件检查完成，**尚未安装、未上传、未启动或操作游戏**。用户要求先完成，再由用户退出游戏后覆盖；不能在本轮结束前自行安装。

## 范围

只整理现有 Main/ModelSession、配置应用与资源退出，不增加总管理框架、依赖、线程、求解器、物理频率、绘制 Pass 或逐人物/动作/物品补丁。工作台、外部光影与渲染支持未改。

1. `Main` 为每个角色最多保留一份准备中的候选。候选完成实际姿态输入与 GPU 网格准备后，由捕获入口接替当前人物，再让旧会话按宿主 Retirement 退役。准备期间原人物继续更新；首次启用时保留原版绘制。失败、被后续请求替代、关闭人物和 clear 都取消候选。晚到的上传会检查 retired，晚到的交接只接受当前候选身份。
2. 菜单启用请求不立即保存、发布联机外观或切换语音；Lua 仅在等待中的切换成功后确认一次。失败保留原保存选择并通知一次，恢复原人物语音状态。菜单先检查切换失败，再检查原人物就绪，避免把回退误认为成功。现有存档字段和公开方法签名保持不变；真实多人未测。
3. `ModelAppearance` 分开准备和应用；`PmxModel` 先检查外观、武器矩阵和胸部参数，`ModelSession` 先检查自身配置结构与贴图路径。无效输入不会先提交外观。可恢复的应用异常会尝试恢复原物理参数和原生外观；回退失败保留为 suppressed exception，不宣称可恢复原生内存损坏或 JVM 致命错误。
4. 小型 `ResourceCleanup` 按所有权逐项关闭资源并保留首个及后续异常；网格、贴图工厂、模型与会话重复关闭不重复释放。会话的退役回调即使一项关闭失败，也继续处理其余资源并清空持有引用。未扩大为对宿主所有回调的通用异常拦截。

正常播放的动作重定向、骨架、物理求解、默认值、70%空手手型、60Hz、语音内容和材质算法不变。切换时新旧模型短暂共存，至候选提交或失败退役；未承诺实际 FPS 或峰值内存改善。
