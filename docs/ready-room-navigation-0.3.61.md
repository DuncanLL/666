# R116 0.3.61 整备室导航和表情

基于 0.3.60。总览只显示各工具的入口。换装页在穿着按钮左侧提供白底的「部件切换」。基础配件和详细部件合在同一页，返回依次回到换装、总览。各工具页仅显示当前工具。握持页保留实时人物绘制，未装备枪械时右侧提示装备。顶部添加半透明标题栏和常显返回键，头像、展开键及功能图标放大。

睁眼与闭眼移入表情页。优先使用皮肤已有的眼睛切换配置，其次使用模型的闭眼表情通道。自然、微笑、惊讶和生气按模型现有通道应用。自存预设只显示五格，旧存档中其余预设数据保留。

使用游戏的 ISButton 和 Kahlua 检查了换装、部件切换、返回路径、握持页实时绘制调用、眼睛操作、表情预设、五格保存和关闭重开。逐个读取了现装 21 套可见模型的表情通道。游戏退出后同步本地 MOD 和工坊作者目录并逐文件回读。实机画面与表情观感待验收。
