# R116 0.3.76 阶段记录

记录日期为 2026-11-13，涵盖 11 月 12 日晚至次日凌晨的整备室改版、资源兑换、角色抽取、衣装购买及语音核对。基线为 0.3.52 的八人语音接入提交 `dd4c771`，本阶段对应已安装的 R116 0.3.76。

用户已告知 Steam R116 下架。本阶段在 GitHub 保存源码、配置、外置资源指纹和验证说明，供后续维护与恢复使用。

## 人物、资源与声音对照

本阶段同步实际安装中的 15 位角色、39 套可见造型，以及 1 个旧存档兼容模型。人物本体和九个独立角色包的注册、profile、整备室卡面索引与语音映射一并归档。模型、纹理、音频及原游着色资源通过 [外置资源清单](../resources/manifest.json) 按路径、大小与 SHA-256 对照。

克莱妲、妮基塔、芙洛伦、埃芙、桑朵莱希、黛烟、可露凯、OTs-14 共 1,384 条语音。当前本地与工坊作者目录逐条核对一致，覆盖 23 套造型的绑定。既有夏安、阿斯缇亚、莱娅和芙铃沿用现有语音。春田、索米、希丽雅尚缺对应语音素材包。

其他人物分支中已安装的旧版材质槽迁移逻辑也已纳入，以便旧外观设置继续映射到新版模型。可露凯后马尾的修正通过现装 profile 与外置 PMX 指纹归档。

## 验证与待完成项

- 177 份运行配置及脚本与本地、工坊作者目录对应。
- 46 份 Java 源文件编译通过。按既有合包入口挂接后，87 个类的规范化内容相同，Main 的类头、字段和 78 个方法内容相同，方法排列顺序有差别。
- 钱包回归使用游戏自带 Kahlua，覆盖一次性重置、三种余额归零、重开后保留新进度、直购、衣装独立保底和角色共用保底。可运行 `python tools/check_room_economy.py`。
- 既有阶段检查覆盖游戏原生按钮处理、预览调用、长列表拖动、表情控件、结果播放、原版声音脚本解析及 23 套造型语音触发。最近游戏日志记录到部分角色的实际播放事件。
- 本机 AMD 的预览程序编译链接在 0.3.63 阶段通过。实际游戏画面、动效和听感仍待用户验收，其他显卡、真实多人及订阅冷启动验证待完成。
- 其余角色与衣装文案待补齐。新增文案字图使用了本机通用字库，后续统一原游字体与排版仍需复核。
