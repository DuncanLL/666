# 少前2追放角色框架 0.3.80 角色工坊入口

框架工坊简介使用 Steam 原生排版标记展示五列三行头像网格。15 张头像及角色名分别链接到对应角色模块的工坊页面。服务器返回的实际 HTML 已核对 3 行、15 个单元格、15 张图片链接及名称对应。[简介源码](workshop-character-directory.bbcode)

整备室的未载入角色界面新增「前往角色工坊」。首次点击打开确认框，显示当前角色名与 Steam 创意工坊目标。确认后优先打开 Steam 浮层，浮层不可用时打开对应网页。取消、返回、关闭窗口、换角色或切换页面时清除确认框，旧确认回调失效。首次按钮位于确认按钮之间的空隙，弹窗覆盖底层输入。

全部 15 位角色的工坊 ID 在 roomWorkshopItems 中登记。已经载入的角色不显示该未载入入口。保留模型、外观和钱包既有的稳定身份。

已使用游戏 Kahlua 与原生按钮处理验证全部 15 位角色的首次点击、取消、返回、确认、重复确认、模态遮挡，以及浏览器与 Steam 浮层两种目标。游戏内界面和浏览器实际打开效果待用户实测。

本地与工坊作者目录已更新至 0.3.80，核心工坊项目已完成内容更新。角色页面及依赖继续使用已发布的项目。
