# R116 0.3.63 整备室镜头与资源兑换

基于 0.3.62。右侧长面板支持按住空白上下拖动和滚轮滚动，滑块、按钮和滚动条保持自己的鼠标交互。实时人物可左右旋转、上下平移和滚轮缩放。表情页用模型头骨高度作为近景目标，返回时恢复进入前的镜头。面板用同一整备室背景的预模糊版本做磨砂透底，按钮和边沿增加浅高光和深色收边。

右上角显示专访许可、新装许可和信用币。每项的加号打开对应的数量、消耗和确认弹窗。按 PZ 原版 Base.Money 计数，1 张换 10,000 信用币，两种许可各为 120 信用币一张。余额保存在玩家的整备室资料里，确认时重新核对背包与余额。索米、黛烟作为未解锁展示，实时人物着色为半透明虚影并叠加锁，人物下方显示访问一次和访问十次及其券数。访问入口目前没有抽取和扣券动作。

已用 PZ 自带 Lua 和按钮点击处理检查余额、换汇、余额不足、锁定、镜头、拖动和重开。预览 OpenGL 330 程序在本机 RX 9070 XT 的受控上下文编译链接通过，其他显卡和真实游戏内验收另计。已安装本机 MOD 与工坊作者目录，逐文件校验通过。
