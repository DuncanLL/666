## 光影与构建

Native 光影显示名更新为「少前2追放角色光影 Native」。Native 与 Eclipse 的人物选项分组更新为「少前2人物效果」，英文分组为 GF2 Character Effects。相关构建、打包及验证工具采用新名称，核心工坊编号从实际项目元数据读取。

实际 JAR 的变更范围为一个界面分组字符串以及两份内嵌光影包的显示文字。逐条比较确认其它 JAR 条目相同，光影程序文件内容相同。已用实际托管安装器核对两套光影的安装与显示文字。

## 安装与上传

已同步本地和工坊作者目录的名称、封面与 0.3.79 版本。旧核心项目已失效，核心新建工坊项目，埃芙更新原项目，其余角色按当前项目元数据创建上传。

本轮已获用户授权试上传。16 个项目均完成上传，沿用 unlisted 可见性。角色项目依赖新核心，核心项目依赖 ZombieBuddy 与 Viewpoint。通过 Steam 接口回读名称、内容大小、依赖 ID 和封面，远端封面与本地上传 PNG 逐像素比对。

[改名、头像来源及验证摘要](../provenance/framework-branding-0.3.79.json) 记录对应素材与包指纹。当前工坊编号存于各实际上传目录的 workshop.txt，本地回读记录保存上传结果。
