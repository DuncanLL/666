# R116 0.3.53 整备室

2026-11-12。基线为带八位角色日语配音的 0.3.52（dd4c771）。

- 总览提供可滚动的圆头像栏和三列卡片，使用各角色默认头像。选中头像有环形高光，矩形卡使用黄橙描边。沿用机库背景原图，扩大界面并按原比例绘制。
- 选人与试穿使用独立预览。应用角色或换装仍由既有的启用入口保存。未载入角色显示暗头像、锁和工坊订阅提示。
- 换装页保留人物展示，卡片可点选、滚动或拖动，切换时滑动和缩放。收录了从原游表核对的七套皮肤介绍。单抽、十连和皮肤购买为按对应锁定状态显示的界面占位，兑换与抽取规则另定。
- 三个 UI 音效来自本机少前2的 UI_System.acb。角色选中对应 UI_System_Main_Click_Normal，切页对应 UI_System_Main_Click_Tag，启用确认对应 UI_System_Main_Click_Confirm。按各 cue 的音轨映射解码，切页混合两个音轨，均转换为 48 kHz 单声道 PCM。

通过 PZ 随附 Kahlua 的交互检查，覆盖展开、点击、换装浏览、锁定提示和显式启用。Java 对现装宿主编译通过。合包只替换两份整备室相关类和加入一份预览记录类，校验另外 243 个条目内容一致。已同步本机 MOD 和工坊作者目录并回读。实际游戏内 3D 预览、动效手感与音量待验证。
