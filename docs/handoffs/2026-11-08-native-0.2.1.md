# Native 0.2.1：预设反射输入与人物提交开销

- 修复独立接入层的反射计算输入：复用官方 `WeatherMap.samplers`，将 `uCloudNoise`、`uWeatherMap` 接到官方槽位 18、14。此前新增云反射消费者与深度采样器共用默认槽位 0，AMD 驱动在真实调度时返回 GL_INVALID_OPERATION；验证信息明确为不同类型采样器共用纹理槽。该问题是极致人物黑色的候选原因，实际用户存档尚待复测。
- 性能：每个原材质提交改用官方已有的单项候选绘制入口，避免每次扫描全部模型；保持原批次、筛选、顺序、状态、LOD 与待加载资源处理。缓存原几何参数的位置及复用读取缓冲，仍按每次提交读取当前值，不降低任何更新频率。
- 未修改材质参数、模型、贴图、原游程序、场景光影、预设或 VP 文件；无角色名、模型身份或地点特判。
- AMD 9070 XT 受控实际调度：夏安 Ultra、科莱达 High、阿斯缇亚 Low 夜晚室内均无 GL 错误。三种资源未就绪及恢复检查通过。未在游戏中操作用户存档。
- 分离反射修复与性能改动后对比同场景 720×900 输出：648000 像素中 7 像素相差 1/255，平均绝对通道差 0.00000566；不声称字节完全相同。短跑耗时存在波动，不发布 FPS 提升百分比。
- 正常 Java MOD 入口、空白中文路径安装、用户自改包保护、资源检查及官方工坊目录验证通过；不等于真实订阅冷启动或 NVIDIA 实测。
- 本地详细证据位于被忽略的 `build/native-issue-20261108`；受控运行沿用本机已有诊断夹具。仅更新本地目录与授权的 Steam 安装，不上传工坊、不推送 Git。
- 旧 Native V4/V5 包已有官方接口编译错误，应移出活动 shaderpacks；当前 Aimoh-Native-GF2 属于合法 Native 包。官方 Iris 扫描器也扫描其 shaders 目录并报告缺少 Minecraft 入口，该提示不等于 Native 加载失败；不能删除当前人物着色资源来消除提示。
