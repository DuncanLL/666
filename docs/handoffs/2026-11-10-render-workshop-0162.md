# R116 光影适配正式工坊 Viewpoint 0.1.6.2

独立光影 MOD 0.3.25 在同一分发包提供 Aimoh-Native-GF2 和 Aimoh-Eclipse-GF2。工坊项目为 `3834707439`，内部 ID 为 `AimohGF2Eclipse`。配套人物运行时为 0.3.35。

目标宿主是 Viewpoint 工坊项目 `3809306528`、Steam 清单 `559614409211759918` 的原始 JAR，SHA-256 为 `67f83b05a27c4112ce9edc596da7c491d51e9015862dccafa8495f0b9352625e`。该清单没有独立的 `.jar.zbs` 文件。宿主的字节由分发和加载两端校验。

- 两套光影使用正式宿主的模型纹理缓冲、绘制批次、地形凹凸贴图槽和灯光接口。
- Native 使用正式宿主的天空光系数贴图和浮点世界法线，人物材质仍从实际场景取日照、阴影、反射和间接光。
- Eclipse 车窗由正式宿主的原生车窗路径绘制。RC4 单独提供的挡风玻璃雨水和雨刷覆盖层依赖正式版缺少的接口。

在 AMD Radeon RX 9070 XT 上以工坊原始宿主和人物 0.3.35 做离屏验证。Native 验证了克莱妲的专用材质、阴影和运动向量。Eclipse 开启 TAA 后画出了克莱妲的专用材质，并通过 29 组展开后着色器的 OpenGL 参考链接。此验证范围为 `LIMITED_HARDWARE_VALIDATION`，真实进档和 NVIDIA、Intel 仍待验收。
