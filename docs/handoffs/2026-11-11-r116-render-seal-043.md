# R116 0.3.43 光影封装

以 0.3.42 单 MOD 为底包重封 Native 和 Eclipse。发行包中的密文资源、着色器标记和解封调度类名由构建种子派生。密钥材料通过生成的状态机解码，分支依赖前一步还原的值。AES-GCM 与类文件摘要继续校验密文和加载器的对应关系。

封装生成器在 `tools/protect_render_release.py`。日常维护使用原始 Java 和 GLSL。受保护的类和密文在发行构建中生成，种子和构建映射只用于私有构建目录。声明 `R116-RENDER-NOTICE.txt` 随合包保留。

用两个独立构建核对命名和标记轮换。两份包各自通过 Java 解封验证，19 份内容与 0.3.42 逐字节一致，类重转换后会拒绝继续解封。正式 Viewpoint 0.1.6.2 的启动、工坊结构校验和旧托管光影升级通过。三次独立 JVM 的首次解封中位数为 0.3.42 的 36.903 毫秒和现装 0.3.43 的 35.256 毫秒。

AMD RX 9070 XT 上同场景离屏各绘 5 帧，Native 与 Eclipse 的 OpenGL 错误均为零。对照末帧的平均 RGB 绝对差在 0–255 标度下分别为 0 和 1.144。游戏实机和新包的外部逆向耗时待验证。

工坊项目 `3834454638` 的作者目录、本地 MOD 和 Steam 本机缓存已读回同一份 0.3.43。安装 JAR 的 SHA-256 为 `9e630f357f3c5933edd4164d2e11f3464ba64db3f895c71b4c25500a002b2647`。工坊上传由作者操作。
