# Native 0.2.6：公共人物渲染性能与发布候选

保留 0.2.5 的人物显示、0..1 实时滑块及菜单编译修复。针对玩家切到少前2专属人物后持续掉帧，优化独立渲染支持层；官方 VP、人物核心、模型、原贴图、动作与物理不修改。

## 本轮修改

1. 阴影材质状态使用既有公共缓存，停止逐部件、逐阴影视角序列化再解析完整 JSON。动态阴影偏移仍按当次宿主状态写入。
2. 每个绘制任务只在实际提交回调中应用一次原材质状态，去掉紧邻的重复应用；绘制顺序与批次资格筛选保持。
3. 地形浮雕参数每个早期/阴影/颜色阶段读取一次，再供该阶段各个部件使用；不跨帧缓存动态值。
4. 寄存器上传使用既有 GL4.5 直接缓冲更新，避免每次读取、切换、恢复通用绑定；布局和字段形状在创建时解析，动态值的长度与有限值检查保留。
5. 反射几何着色器在六个立方体面上做保守齐次裁剪：仅跳过全部三个顶点同处某裁剪平面之外的三角形。跨近面、跨边界三角形继续交给原裁剪器。
6. 反射捕获的墙面已提供当前场景辐射时，不再无条件计算被覆盖的天空与云。
7. GGX 过滤的每组 64 个像素共享相同的 128 个采样方向，保留原采样顺序、分辨率、mip、粗糙度和每帧更新。所有线程先过 barrier，再检查边界，兼容不足一组的小 mip。
8. 逐材质 Pass 查找与绘制队列改为一次解析并缓存；缓存完整原始 Pass，不改变禁用状态、透明排序或材质值。
9. 原程序寄存器布局、SH 连续偏移及主光字段偏移按程序与寄存器缓存，不在每次绘制/上传时重新扫描 JSON。动态寄存器仍逐阶段按原时机更新。
10. 阴影先收集当前视角真正合格的部件；空集合直接跳过人物准备，避免在不投影的灯/级联中构造完整人物寄存器。
11. 修复多人物材质绑定缓存抖动：反射 cube/阴影 ID 改变时不再清空全部绑定。保留固定纹理与原采样器，仅更新缓存中明确标记的动态引用；不会按人物复制完整缓存。

## 后续深查覆盖与保留成本

- 冷加载、纹理上传、原程序改写/编译：已有按源身份缓存，普通帧没有重复纹理上传或源 SHA 读取，不另加第二份纹理字节缓存。
- 模型加载等待、可见性、阴影候选、早期/颜色各阶段：保留宿主实际批次资格与原阶段顺序；空阴影准备与静态资料重复处理已改。不能为了提速删掉发影、透明、轮廓或皮肤原材质阶段。
- GL 状态边界：保留恢复，避免污染 VP 场景。逐阶段合并模型 begin/end 没有明确额外收益，候选撤回。进一步跨宿主调用缓存 GL 状态会有失效依据不足的问题，不靠猜测取消恢复。
- 反射捕获、天空/云、GGX：本轮减少无效输出、无效天空追踪和重复数学运算；不使用固定房间反射、不跨位置共用角色 cube、不减少更新次数。真实城市复杂几何、动态覆盖与低端 GPU 的收益仍须实际测试。
- 颜色/深度复制、原运动/法线桥接：仍承担整幅缓冲成本。局部矩形更新涉及原轮廓/透明深度/场景信息所有权边界，尚无完整边界证据，本轮不冒险裁切。
- 选灯：保留宿主灯输入与按人物范围选取的原有上限，不删灯。显示查表保持两张小表及设置变更时才重建，不将用户强度滑块做成每帧重建。
- 生命周期与分发：缓存均归当前 renderer/materials；切包释放，公共入口、版本/资源身份检查保留。模型/物理核心属于另一维护线，本轮没有为渲染提速改变动作、物理频率或保护资产。

没有通过关闭阴影/反射、缩图、降低模型精度或减少更新频率来提速。分组模型绑定的候选没有带来额外明确收益，已撤回。

## 性能与效果证据边界

本机 AMD RX9070XT、官方 VP 0.1.7-rc2，720×900 私有实际宿主场景、Ultra。正式对照移除了诊断专用的同步遮挡查询，排除最初预热帧。计时范围是实际 `fixture.draw`，不包含其之前的 PMX 提交/物理计算，不能直接换算玩家完整游戏 FPS。

- 科莱达完整最终候选：修改前渲染帧中位 9.679ms，最终 7.042ms，约少 27.2%；两者最终输出像素 SHA 相同。
- 首批 CPU 优化对照：夏安 16.433→9.309ms、阿斯缇亚 13.635→9.706ms、夜间室内科莱达 9.791→7.133ms；各自输出 SHA 相同。这些是首批阶段数字，最终 GPU 改动的覆盖见本机新报告，不能把阶段数据冒充全部最终测量。
- 双人物首批对照 17.747→10.782ms，绘制阶段、数量、资源离场释放一致；前后仅 89 个像素变化、最大通道差8。旧版重复自身也有 96 个像素变化、最大5，所以此场景不声明逐字节相同，保留重复基线记录。
- 深查后的最终同条件 64 帧对照（排除前20帧）：夏安 16.433→7.922ms（少51.8%，输出完全相同）；阿斯缇亚 13.635→8.201ms（少39.9%，648000像素中5像素变化、最大通道差3/255）；双人物17.747→9.910ms（少44.2%，104像素变化、最大6/255）。均无GL调试错误；这些是本机合成场景的渲染耗时，仍不代表全游戏或其它显卡FPS。
- 最终批次通过真实静态/实时菜单切换、46组当前程序与材质上传读回、加载中批次跳过/恢复、夜间拥挤灯及六向房间反射检查、两轮切包资源释放。旧生命周期组合脚本把“立即关闭显示资源”与“后续循环快照”同时使用会因 renderer 已关闭而失败；最终分离职责后用正常生命周期入口通过，不掩盖旧失败。旧 repeat 采样专项夹具缺见证仍不声明通过。
- 日常主链的开销包含原材质多阶段、额外阴影视角和当前场景反射；不能仅凭普通人物卡更快就归因为贴图尺寸。没有测出低配显卡或 NVIDIA 的真实收益。
