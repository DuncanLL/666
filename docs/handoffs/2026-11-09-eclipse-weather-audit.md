# Eclipse 0.1.7 夜间天气检查

用户描述为夜晚雨天或有雾时天空、雾层局部闪烁。旧的 F 盘 `e597098e` 雨雪修复保留。在历史稳定包、F 盘保存的包和 0.1.6 候选中，天气片元、`gbuffers_weather`、体积雾和原有合成阶段的相关源码字节一致。旧天气片元修复写入中性 MRT 输出，避免未定义值混入透明分类和场景色。本次仍逐字节保留该文件。

## 查实并修正的缺陷

- TAA 的历史亮度差原先除以裁剪后的历史 RGB。黑色像素可能执行 `0/0`，新版本保证分母为正。黑对黑时附加响应为零。
- 体积雾的双边升采样在边缘可能从深度纹理外或缩小后尚未写入的雾区域取样。限制两组整数采样坐标，并限制低分辨率雾输出的填边像素反查全尺寸深度时的坐标。数学检查覆盖 640×800、体积雾比例 1、0.5、0.25。
- 积雨云闪电开启时，`composite3` 片元写入云深度 image，`composite4` 读取。官方 RC3 的屏幕阶段没有在这两次访问之间设同步。通过 Eclipse 接入层在实际链接了云深度读取的 `composite4` 之前补对应 barrier。当前 F 盘保存的配置中积雨云强度模式为 0，这个缺陷与用户反馈的同源性未证实。

## 受控对照

- 使用官方 RC3、现有人物资料与保存的 Eclipse 参数副本，分别跑过夜间干燥、雾、雨、雨雾、关闭 TAA、雷暴及降雪。用真实 IrisFrame 天气、雾与颜色阶段。固定环境对照没有复现用户所述局部闪烁。
- 带实际地面网格的夜雨雾前后各 192 帧。通过深度分出天空与场景，并在 `composite3` 和 `composite4` 各读回天空和近地雾。热身后天空相邻帧最大平均亮度变化小于 0.083 个 8-bit 灰阶，两个雾阶段的样本均有限。半分辨率雾转镜头、启用云深度的雷暴分支另测。注入真实闪电时天空仍出现显著亮度变化。
- 候选通过正常分派、人物资料契约和工坊目录检查。48 组人物原程序及材质缓冲读回通过，宿主展开后的参考 GLSL 检查共 165 项通过。实际 AMD 绘制无 GL 错误，NVIDIA、Intel 与用户原场景尚待复测。

候选与证据在本地 `build/eclipse-weather-audit`。Native、官方宿主、人物核心及现装设置保持原状。真实雨雾中的那次闪烁仍需对上触发时刻，不能用这三项确定修复替代用户场景验收。
