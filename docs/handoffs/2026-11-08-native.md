# 2026-11-08 Native分发主线迁移

用户明确要求把Native开发成果接入当前仓库的光影分发器，Steam那套移除Eclipse，改以官方VP默认环境＋少前2人物渲染为准。此指示取代此前render-support仅冻结Eclipse的限制。人物、动作、物理、贴图和语音不改；F测试安装不自动覆盖。

- 渲染支持0.2.0；内部ID仍为`AimohGF2Eclipse`，名称`R116 渲染支持 光影分发`，无可见简介；现有工坊项目3834707439保留。
- 仅内嵌`Aimoh-Native-GF2.zip`。正常ZombieBuddy授权后自动安装Native目录，玩家选择该包；没有Eclipse载荷或Iris绘制挂接。历史协议字符串仍保留以兼容现有人物资料，不表示分发Eclipse。
- 支持已验证的官方VP 0.1.7-rc2（指纹见provenance），拒绝未知构建和重复接入包；人物核心接口预检。官方VP文件不被接入层改写。
- Native沿用原版环境和后处理，仅接人物程序、真实贴图和公共灯光输入；相机方向人物灯按用户例外保留。
- 已带入：显式且匹配的阶段接口；纹理上传unpack/PBO隔离；原格式/尺寸检查；按宿主已就绪批次绘制；资源加载失败不锁死同一光影；构造失败释放；每人物寄存器/反射所有权与切包释放。
- 原游着色资源通过人物MOD相对路径读取。444份约600MB资源的异地Unicode/空格路径读取和损坏/缺失检查已做；这不是实际Steam订阅冷启动。
- 本机AMD受控链接、绘制、资源等待/恢复等检查有证据；NVIDIA硬件、完整多人、长期稳定性、真实订阅冷启动未标通过。原游完整功能变体、部分人物后处理及反射完整度仍在后续范围。

构建与工坊候选：`python tools/build_render_support.py`、`python tools/package_render_support.py`、`python tools/check_render_support.py`。测试agent由仓库测试源码生成，只在受控检查使用，不进发布包。发布仅提供游戏认可的Workshop目录，不自动上传Steam。

本机迁移/备份与检查记录留在忽略的`build/native-migration-20261108`，不把游戏资源、日志或大包提交Git。
