# Native 0.2.7：人物专用菜单与轻量体表调节

按用户授权增加可选人物材质增强，默认关闭；不替代原游还原基线，不修改场景效果或人物资产。

## 设置与菜单

光影选项中独立分区 `R116 人物效果`，集中列出人物柔和底灯、原游人物显示还原强度、体表细节增强、皮肤光泽增强。两个新项范围 0..1、步长0.01、默认0、kept=true。旧项键名、默认值与玩家存值保持。

官方 rc2 的 pack.properties 没有菜单分组字段；独立接入层仅在内存中为 `PackOption.declare` 的这四项替换 section，使用原设置行、可见性、保存、预设与实时参数机制。其它选项继续走原section。增加一个严格签名/数量检查的挂接目标，不写或分发官方VP类。

## 材质实现与边界

- 只处理原程序明确登记 `_BumpMap`、`_RMOTex` 且可识别其真实采样/解包表达式的路径，不额外读取纹理。原法线 XY 最大放大到1.5倍，后续仍使用原程序重建Z及变换归一化。
- 原RMO.r在当前程序同时控制BRDF粗糙度及反射LOD。光泽增强最多乘0.75，并以原金属度G衰减，保持原反射、灯光、遮蔽与能量分配计算；没有直接往最终RGB加亮。
- 材质权重沿原 `_UseGIFlatten` 值，缺少此输入权重为0；它是原受光路径选择，不是从肤色或角色名猜皮肤，也不宣称它在所有未来原程序中都是普适皮肤分类。现用衣物此值为0，面部等原路径可能为1；只有还具有相应纹理/解包输入时才接新运算。
- 不按人物名字/ID/模型SHA/部位坐标做补丁，不重写贴图。新程序表达式不匹配时保留原文，不能靠猜变量或通道硬接。新角色仍需核其实际输入支持情况。
- 早期法线与颜色阶段共用同一增强，避免颜色细节与Native间接受光/反射法线不一致。既有原始几何阴影保持。
- 只增加少量算术与每部件一个vec3参数，不增加纹理读取、Pass、灯光、反射捕获或全屏后处理；没有承诺绝对零成本。
