# R116 0.3.38 角色子模块

从已装的 0.3.37 单 MOD 合包拆出三个角色，保留模型身份和原有服装。R116 核心继续内置 Native 与 Eclipse，配套宿主为正式工坊 Viewpoint 0.1.6.2。以现装 0.3.37 为基线保留同期的柔边修复。

| MOD ID | 角色 | 原模型 ID |
|---|---|---|
| R116Springfield | 春田／睡醒的人鱼 | pmx-225af1a054faefb0 |
| R116Faelynn | 芙铃／忻跃阳炎 | pmx-293917f24c2bd387 |
| R116OTs14 | 闪电（OTs-14）／默认 | pmx-782f06826adb1307 |

三个包沿用埃芙和桑朵莱希的独立 registry、整备室资料和 GF2 目录片段。核心保留锁定头像和共享数据。芙铃的专用语音随包移动，公共语音路由与静音样本留在核心。埃芙和桑朵莱希的原包同步设为 42.22。

`tools/split_r116_character_packs.py` 从固定 SHA-256 的 0.3.37 工坊目录组装六个项目。核心 JAR 只移出三个模型的胸部物理数据，放入各自模型目录的 `chest.bin`。JAR 内其余条目逐字节校验。

本机 PZ 42.22.2 原生工坊验证、角色包启用和锁定、30 帧胸部物理、Native 与 Eclipse 目录读取均单独取证。三个新包在 AMD Radeon RX 9070 XT 上各跑两条离屏绘制路径。真实进档、声音实播与 NVIDIA／Intel 硬件验证另计。
