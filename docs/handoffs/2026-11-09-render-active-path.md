# 当前绘制路径简化

Native 0.2.13 与 Eclipse 0.1.6 均面向官方 Viewpoint 0.1.7-rc3。两份候选分别保留工坊项目 3834707439。

- Native 的反射采集直接写入成品立方贴图的 mip 0。GGX 滤波仍显式采样 mip 0，只写 mip 1 至 6。各级精度、格式和滤波参数照旧。移除一张 192 KiB 的共享中间贴图及每次人物反射更新的一次六面复制。颜色拷入工作目标后，运动贴图直接清除，省去重复挂接同一组附件。
- Eclipse 按早期深度与后续颜色阶段各准备一次绘制目标。后续颜色统一读取和绑定场景曝光及公共环境，人物仍分别计算对象光照、阴影与模板。深度回写和运动解码在该阶段所有人物绘制完成后执行。
- Native HDR 目标是 `R11F_G11F_B10F`，而当前人物显示转换以 `rgba16f` 绑定颜色工作图。HDR 工作图及其往返依旧使用。人物模板依赖 packed depth/stencil，当前深度搬运也仍保留。

受控对照使用夏安日间、科莱达室内夜景。Native 新旧七级立方贴图的 RGBA16F 读回一致，最终画面逐像素一致。Eclipse 开启响应式 TAA 的双人物对照均提交 60 个人物部件，最终画面逐像素一致。两版均通过异常姿态恢复、当前人物目录、启动和工坊结构检查。

OpenGL 参考编译和链接通过 Native 85 项及 Eclipse 77 项。AMD 受控绘制无 GL 错误。两份报告均为有限硬件验证。对照计时有升有降，真实游戏 FPS、NVIDIA 和 Intel 验收仍待实测。候选和证据在本地 `build/render-active-path`。
