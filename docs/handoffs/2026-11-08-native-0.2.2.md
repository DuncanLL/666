# Native 0.2.2：用户授权的轻微人物底灯

2026-11-08 用户明确要求：人物在偏黄场景下略微白净一些，加入力度克制、可在光影包内调节的底灯。本授权是既有“保持原效果、不加美化修色”边界下的具体例外，只覆盖公共人物补光。

- 光影选项 `characterSoftFill`，显示“人物柔和底灯”，范围 0–0.50，步长 0.01，默认 0.08，随用户设置保留。0 返回原有相机灯颜色；不取消此前认可的原相机灯。
- 复用原有相机方向灯槽。在原材质受光计算前加入轻微偏中性的入射分量，保持原 BRDF、贴图、轮廓与阴影。使用原灯已乘过的环境亮度；零入射不凭空产生底灯。影响所有支持的角色材质，不写身份特判、不只给某个角色打补丁。
- 只修改人物局部灯消费者和 Native 包选项；不修改默认场景的光照、色调、曝光及后处理，不增加灯槽、Pass、绘制次数或采样次数。
- 官方选项解析检查确认滑块可发现、五档预设默认一致并保留用户设置。实际受控 GPU 日景分别运行 0 和默认值，夜晚室内运行默认值，均无 GL 错误。0 与 0.2.1 的 720×900 输出仅 2 像素相差一个色阶；不宣称字节完全相同。默认值的脸部区域平均通道增加约 1/255。
- 实际游戏 UI 调节和用户观感仍待本人验收；未测 NVIDIA，未测真实订阅冷启动。安装仅更新 Steam 支持包及本地工坊目录，官方 VP 和人物资源保持不变；不上传工坊。
