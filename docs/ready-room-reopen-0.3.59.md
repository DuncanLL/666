# R116 0.3.59 整备室点击与重开修复

基于 0.3.58。关闭整备室时销毁窗口记录和输入捕获，下次从游戏菜单打开时创建新的窗口实例。已经打开的同一个窗口收到菜单请求时只置顶。

浏览已载入的外观时，右侧工具可点击。配件、胸部物理、握持和表情面板会提示先启用当前预览的外观，启用后仍停留在该工具面板。重置物理和动作预设也提供同样提示，并且只作用于已启用的当前外观。缺少胸部物理配置时，页面给出对应说明。

用 PZ 附带的 Kahlua 和实际 ISButton 点击处理验证旧版禁用方块及重用移除窗口的问题。新版通过六次连续重开、加载和折叠状态下关闭、切换配件、胸部物理有无配置、换装、动作预设和未载入角色状态检查。游戏退出后同步到本地 MOD 与工坊作者目录，逐项回读通过。实机复测待确认。
