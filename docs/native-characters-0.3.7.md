## 公共纹理格式补齐

实际Native绘制曾在芙玲原始4×4法线`flat`报 `Unmapped original texture format 12`。Unity格式12是DXT5/BC3：添加既有S3TC上传分支和正确16字节块大小，完整保留48字节、3级mip和原色域；没有转PNG、重烘或缩图。

Native主线源码提交 `828a8105fc0805e6767049d2f648b1c7f91db431` 只涉及 `AimohGf2OriginalTexture.java` 的3增2删；未提交另一工作区其他进行中的Native改动。本分支保留同一差分于 `provenance/native-dxt5-20261108.patch`。F旧测试接入层无UnpackScope，使用经逐字节运行类对照确认的对应旧源，单独增补DXT5；未将Steam Native-only整包覆盖F。

安装只替换F用户、Steam订阅位置及Steam渲染支持工坊项目的该纹理类，JAR其余项（含内嵌光影）逐字节不变。现有渲染支持版本名称保留，精确新旧JAR指纹见本机安装回执。

## 胸部物理与旧系统

检查发现春田已经携带新版FEM绑定，默认物理开启、强度100。实际180帧舞蹈组件测试无报错，采样最大形变约0.21368模型单位，按其比例约0.01001世界单位；不是游戏观感或FPS测量。因此未重复添加第二套乳摇、未调整效果参数。

当前游戏核心只调用`ChestSoftBody`新版形变；没有旧增强器运行代码/原生库并行计算。新版绑定加载时将对应胸骨交给动画所有权，保留头发、衣服与作者碰撞。没有为了“移除旧系统”删除这些基础碰撞或整套MMD物理；工作台不在本轮范围内。
