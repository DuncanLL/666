# R116 0.3.75 整备室衣装采购

基于本机 0.3.74。已解锁人形的原皮随人形开放。普通衣装使用 1 信用币购入，获得后可以在换装页穿着。三套限定泳装使用新装许可，分别是克莱妲「濯浪焦点」、春田「睡醒的人鱼」、可露凯「蔚蓝轨迹」。春田原皮接入前以「静享芳醇」暂代。

选中未获得的限定衣装进入新装采购页。中间显示实时模型，左侧显示原版横幅和衣装介绍，右下角提供单抽和十连。复用整备室逐抽揭示和音效。每个衣装池分别保存进度，十连命中后停止并按实际访问次数扣券。三位人形的简介和八套衣装的介绍来自本机游戏文案表。

本机《少女前线2：追放》的 GachaClothesData 表中，三池限定衣装的综合概率均为 1.18%。LangPackageTableCnData 的对应说明写明 100 抽硬保底、池间计数独立。详细公示用参数占位表示逐段增幅。R116 此版先按用户提到的 120 抽做保底。暂定基础概率 0.10%，第 26、50、70、80 抽开始分别每抽增加 0.02、0.04、0.07、0.12 个百分点。此版只结算所选衣装的获得和未中结果。

通过游戏自带 Kahlua 与 ISButton 验证信用币扣除、重复保护、新装许可扣除、120 抽保底、三池独立、原有角色池继承、按钮热区、逐抽结果和重开读回。实机画面与操作手感待验收。已更新并逐文件回读本地 MOD 和工坊作者目录。
