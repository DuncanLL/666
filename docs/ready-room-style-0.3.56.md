# R116 0.3.56 整备室样式复核

基于现装 0.3.55 的克莱妲改动。整备室背景贯穿整个视图。左上使用返回箭头，左侧保留滚动头像和展开按钮。右侧人物名和六个短功能按钮沿原游戏的位置和比例排列，重置物理在右侧。底色、黄橙选中边、头像明暗和底部按钮取样自原游戏参考截图。换装标题、角色名和说明在左下，右侧用高亮皮肤卡。

固定文案和已知角色、皮肤名称来自本机《少前2》resources.assets 内实际提取的 HarmonyOS Sans SC Bold 与 Medium 字形，共 161 张小字图。改版保留已有的选择和页面动效。

整备室中央实时绘制当前浏览的人物与皮肤的 3D 模型。加载期间或绘制失败时只显示对应文字，右侧换装卡承担皮肤卡面的展示。上一轮离线样图中的中央卡面是旧版显示方式。

通过 Kahlua 交互及绘制检查，覆盖总览、分组展开、换装、返回和未载入提示。游戏退出后已同步本机 MOD 与工坊作者目录，两个副本均逐文件回读通过。实机 3D 和动效待验收。
