# R116 0.3.78 一位角色一个 MOD

本次将莱娅、夏安、阿斯缇亚、克莱妲、妮基塔和芙洛伦从公共核心拆成六个角色 MOD。现在共 15 个角色包，每个包包含该角色的全部已接入造型、对应配置和已配套语音。公共运行时、整备室和共享资源由 R116 提供。

所有角色包通过 require=\AimohPmxPreview 声明对公共核心的依赖。原有九个工坊项目的 ID 和元数据保留，新六个目录使用标准 Workshop 项目结构。原模型 ID、39 套可见造型和莱娅的隐藏旧存档模型均保留。

## 验证及安装

15 个包分别通过现用游戏 Java 加载入口检查。仅启用核心、核心加单角色、核心加全部角色三种配置均已检查。原有 40 个注册模型 ID 完整，39 套可见造型和角色名称对应。

使用现装渲染读取器实际合并拆分前后的资料，以材质名称规范化槽位后完整内容相等。PMX 指纹逐个匹配，运行 JAR 字节一致。16 个 Workshop 目录通过游戏内置目录验证器。实际存档游玩和视觉观感待用户确认。

已在游戏退出后同步本地 MOD 与工坊作者目录并逐文件回读。默认启用列表和现用存档补入六个新包，使此前随核心可用的角色继续启用。
