# R116 0.3.70 人形采购与逐抽显示

基于 0.3.69。当前 15 位人形使用同一个抽取流程，各自有官方卡池横幅和属性资料。莱娅与夏安初始可用，其余 13 位默认待解锁。角色包已载入且角色未解锁时可花费专访许可访问。0.3.66 已取得的黛烟和旧保底进度会迁移到新资料。

所有人形池共用一个未命中计数。换池继承，抽中归零。基础概率为 0.6%，第 59 抽起每次加 4.5 个百分点，第 80 抽必定解锁当前人形。十连在命中时停下，按实际抽数扣券。

右侧从所按的访问按钮上方逐抽显示向上移动的结果。未命中时使用暗头像，命中时亮头像和金框。整备室在结果播放结束后开放刚抽中的人形。扣券和解锁随抽取结果一同保存，重开可读回已获得的人形。

已用 Kahlua 和 PZ 原生按钮逻辑验证黛烟 57 抽后转入索米 23 抽、命中归零、旧存档迁移、右侧黑影及金框绘制调用、结果播放结束后才开放启用，以及关闭重开。已同步本地 MOD 和工坊作者目录，逐文件回读通过。真实游戏内的动画观感待验收。
