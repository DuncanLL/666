## 实际修改

1. 胸部体积求解改为Bullet上游的1次Newton预算、1e-4容差。只改自有封装的公共配置；控制笼、七套绑定、四个艺术滑块、内部分步和作者MMD物理60Hz保持。不是退回骨骼摆动。
2. `PmxDrawMesh` 对颜色和阴影都不需要的部件停止填充及上传独立VBO，保留网格、GPU对象及完整骨架/物理。使用实际提交的颜色/阴影规则，不按角色名或材质号筛选。相机隐藏颜色仍需投影的部分继续上传；原程序独立Alpha眼部层为保护排队中的外观变化而保守保留上传。Native原格式流和普通流共用此实现，但下面的顶点节省计数来自基础PMX分块测试，不是所有Native扩展pass的总数。
3. 隐藏后首次重新显示，前一位置取当前位置，避免把隐藏期间的旧数据当运动历史。已有VBO复用，未在每次换装销毁/新建人物。
4. 胸部效果强度0真正跳过FEM；0恢复非零时标记一次软体重置，首次求值重建当前姿态。不自动清除失败状态，不每帧重置，头发/衣物继续原物理。
5. 快照在原有有限值检查中顺便缓存包围盒。历史捕获合并小包围盒，显示插值使用两个来源的保守联合包围盒；保留原安全边距与连续插值。保留全部输入有限值检查，没有为性能吞掉错误。

没有引入额外线程、依赖、逐角色补丁、物理预热或接地IK。没有改原MMD刚体/约束/碰撞规则、动作所有权和70%空手手型。完整顶点快照、Native属性资料与共享物理仍保留；本轮不是把隐藏部件从整个人物计算链中删除。

快照大数组暂不做池化，UV复制暂不改：这两项收益次于已测大头，且需要另核渲染退役寿命/Morph脏状态，不能以复用可变数组破坏已修的连续显示。
