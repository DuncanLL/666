# 少前2追放角色框架 0.7.8

- 支持胸部软体的造型在整备室显示一个「胸部物理」开关，默认开启。打开使用固定的柔软程度 90、回弹阻尼 65、惯性重量 80。关闭停止胸部求解及其变形输出。发型、衣物等仍由常规物理控制。旧版滑条数值不覆盖固定预设。
- 秋桦「秋宴龙厨」和「秋林烈兔」具有胸部软体输入。秋桦默认装和「仁心仁术」的 PMX 未带胸部软体需要的骨骼与蒙皮权重，现有角色包中这两套无胸部软体数据。
- 常规版与 VP RC4 专版均用真实角色资源和录制姿态核对秋桦四套造型的世界帧几何数据。两套有胸部数据的造型关闭后该变形归零，重新打开后恢复。四套造型的常规刚体均有实际输出。另测四个人形的默认预设与 0.7.7 对照一致，关闭状态能从设置重新加载。
- 常规版本机和两套工坊作者目录已回读。老板实际电脑的加载版本、服装和本地或远端角色视角尚待实机确认。
