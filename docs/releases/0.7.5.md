# 僵毁少女前线 0.7.5

0.7.5 常规版面向 Project Zomboid 42.22 搭配 Steam Viewpoint 0.1.6.2，内置 Native 和 Eclipse，支持 24 个角色包。

- 同步原游招募资料、誓约枪皮贴图与名称、角色语音和专武配置。
- 22 把枪械专武的最大射程翻倍。七把专武按 GoM 同类枪调整伤害、命中与暴击。旧枪读档时通过公共兼容层更新原始数值，配件加成保留。
- 整备室椎体强化仍在设计阶段。
