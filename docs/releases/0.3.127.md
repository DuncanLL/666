# 少前2追放角色框架 0.3.127（VP RC4 专版）

2026-11-14

此版本配合官方 Viewpoint 0.1.7-rc4，角色包与常规版共用。安装时选择一个框架。

- 握持校准采用单个近景。拖动旋转，滚轮缩放。物品位置、握点、手腕和手指可独立调整，待机和瞄准分别保存。
- 每条握持滑条可单独归零。整页恢复默认仍可清除当前物品和姿势的全部校准。
- 森牙戾兽采用 5.56 弹药、30 发弹匣和单发／全自动模式。武器脚本、模型、贴图和音效随各自的角色包分发。
- 索普独立分包，包含专武与所需资源。整备室加入索普的工坊入口。
