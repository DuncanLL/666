# 僵毁少女前线 0.7.6

- 常规版与 VP RC4 专版使用相同的固定胸部物理预设，柔软程度 90、回弹阻尼 65、惯性重量 80。其余九个参数沿用 0.7.5 默认值。模型创建时将预设应用到原生解算器，旧存档及角色同步中的 chest_physics 值由固定预设接管。
- 移除整备室胸部物理调节入口。通用的「重置物理」继续用于解算恢复。
- 埃芙角色包更新为 0.7.1。6P33 的 PZ 世界声效半径由 150 降为 30，参照同为固定消音的切尔诺伯格。该字段控制世界声音范围，枪声事件单独定义。

两版均使用各自的 0.7.5 JAR 构建增量。四个人形采用实际 PMX 和原生组件抽测，固定预设与旧版手动设置同样参数的采样变形结果逐字节相同。旧存档参数覆盖检查、Kahlua 编译和 PZ 物品脚本解析均通过。

本机常规版、常规版工坊作者目录、RC4 作者目录及共用埃芙角色包完成安装回读。实际存档里的观感和开枪后的引尸范围需进游戏确认。
