# 少前2追放角色框架 0.7.0

2026-11-14

适用于 Project Zomboid 42.22。常规版搭配 Steam 正式 Viewpoint 0.1.6.2，RC4 专版搭配官方 Viewpoint 0.1.7-rc4。选择其中一个框架，24 个角色包可以共用。

- 索普与碎穹嚎歌专武有独立工坊项目。
- 阿斯缇亚、埃芙、克莱妲各更新 173 句日语语音，字幕和播放时长同步。
- 莱娅、莱娜、索米、维克托使用各自的冲锋枪弹匣，维克托的 EFZ 弹匣容量同步修正。
- 芙洛伦的伊阿索修正持枪方向和枪口挂点，物品图标统一到 32×32。
- 汇总握持位置、单项归零、专武和 RC4 合包光影启动修正。
