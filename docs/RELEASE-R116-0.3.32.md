## 发布核对

工坊项目沿用 R116 的 3834454638。人物运行时 JAR 和内嵌原生指纹见 [发布记录](../provenance/character-release.json)。65 个 Java 类重新编译后与发布 JAR 内容一致，比较忽略调试属性。发布核对复用已验证的原生 DLL。Jolt 包装源码位于 `native/chest-softbody`，依赖 Jolt 5.6.0、Bullet 与 MuJoCo 3.17.0 头文件。游戏通过 Jolt 后端执行胸部求解。

重打包后用游戏原生工坊验证器检查包结构，主包 12 个模型全部通过组件加载。7 个主包皮肤及 2 个独立人物包通过 Jolt 满档与实际 VMD 的半速、停帧检查。整备室三个功能区用游戏 Lua 滑块验证了控制切换。原版猎枪和手枪的握持校准沿用同一 JAR 的克莱妲与妮基塔组件结果。真实游戏画面、FPS、Shoot to Thrill 联动和多人本轮待验收。
