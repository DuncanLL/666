# R116 0.3.76 泳装保底与测试重置

三套泳装的新装采购硬保底为 100 抽，人形采购为 80 抽。下一次打开整备室时，按玩家存档执行一次重置，清空人形抽取获得记录、共用保底进度、三套抽卡泳装的获得记录及各池进度，并将信用币、专访许可、新装许可归零。直购衣装保留。旧记录在同一个钱包内留有备份，重置标记可避免再次打开菜单时清空新进度。

核对其他对话 0.3.52 的语音发布记录和当前实际安装。克莱妲、妮基塔、芙洛伦、埃芙、桑朵莱希、黛烟、可露凯、OTs-14 共 1384 个 WAV，在本地 MOD 和工坊作者目录均逐文件匹配。23 套现有造型的绑定通过 Kahlua 状态语音、普通 Q、潜行 Q、击杀触发检查，游戏声音定义解析通过。当前源码工作树也已同步实际安装中的最新语音绑定。

近期游戏日志记录了埃芙、可露凯和桑朵莱希的播放事件。同状态语音仍沿用已配置的防重复间隔。春田、索米、希丽雅在现有语音包中没有对应素材。真实听感待用户验收。
