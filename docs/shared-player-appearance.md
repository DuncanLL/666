# R116 共享人物外观

PZ 42.22 用 `IsoGameCharacter` 对象选取同一个 `ModelSession`。原版世界和 Viewpoint 世界在游戏线程按 PZ 的帧号更新它。游戏内 3D 人物面板和整备室预览读取已经完成的完整人物快照，第一人称的隐藏头部只作用于 Viewpoint 绘制数据。

原版世界使用 PZ 的静态人物着色器、当前人物相机、照明和目标深度。普通衣物绘制由 PMX 外观接管，实际手持物仍走游戏的装备绘制。安装 Viewpoint 时，R116 合包里的 Native 与 Eclipse 照常可用。只使用原版视角时，模组依赖为 ZombieBuddy。

0.3.47 候选以索米验证。无 Viewpoint 的受控 OpenGL 检查实际绘制了原版世界的人物和 3D 人物预览，两处随同一个外套开关变化。带 Viewpoint 的检查用同一个玩家在两个世界入口提交画面，重复读取同一游戏帧时 VMD 进度保持一致。实际存档、真实场景墙体遮挡、持物观感、其他背包模组和联机需在游戏中另行验收。
