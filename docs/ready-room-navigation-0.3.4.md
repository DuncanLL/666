# 0.3.4：整备室可读性与导航

用户反馈参数字与整备室亮背景混在一起，且配件入口与胸部物理的层级不清。本次只调整菜单，不改模型、动作、物理、Java核心或渲染支持。

- 右侧参数/配件内容使用84%深色半透明托底，皮肤卡片页保持原背景显示。原有加粗参数字、数值和滑块保留。
- `切换配件`与`胸部物理`始终使用同一行、同级入口和当前页高亮。胸部入口直接显示四个滑块及恢复默认，不再将按钮改名为“返回三栏配件”。
- `详细配件`仅在配件/详细配件页的内容上方显示，作为配件的二级页面；返回皮肤保留独立按钮。
- 保留0.3.3的真实子控件顺序修复。真实Java控件顺序、实际ISButton回调及Kahlua布局回归覆盖三种窗口尺寸、四个页面、1296个命中采样点，新增同级入口、直接打开滑块、详细入口可见性和托底断言；原有滑块保存回归通过。

用户随后明确取消“整备室预览继承外部光影”。本次不改变 `ReadyRoomPreview`，不引入预览渲染上下文，不修改已交付的光影分发0.1.1，继续等待反馈方的NVIDIA结果。

菜单元数据为0.3.4，Java核心仍为0.3.1。安装仅更新Lua、菜单catalog的两个文字条目、对应两张新字图及版本；工坊名称、简介、ID均保留。记录在 `build/ui-navigation-0.3.4`，未启动或操作游戏，真实界面观感待用户确认。
