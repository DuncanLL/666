# 0.3.12 整备室资源恢复

用户确认0.3.11帧数明显提升，补充整备室偶发头像/封面缺失、右侧选项无法正常使用。本轮只修菜单资源与窗口生命周期，性能、动作、物理和外部光影保持。

## 已复现与修复

原`image(path)`把`getTexture`首次返回nil永久缓存为false。资源随后可用、反复绘制仍不会再请求。生产Lua在真实Kahlua中注入“先不可用、后可用”的资源时可稳定复现；修复后同一场景恢复头像和封面，配件栏可操作。

- 只缓存成功取得的贴图，暂时未取到的资源后续可再请求。
- 每次打开窗口重新获取菜单资料，刷新按钮同时重取资料和清空窗口图片缓存。
- 跨游戏/窗口生命周期清理Lua缓存，不把旧窗口状态继续当新会话资料。
- Java目录读取不再把可变KahluaTable永久静态共享给所有窗口；新窗口收到独立转换结果。JSON只在打开/主动刷新时读取，不放入每帧更新。

这确认了一个会导致资源持续缺失的实际缓存错误；现有游戏日志没有提供完整UI异常栈，因此不把受控复现写成已证明截图每个症状都仅由这一原因造成。
