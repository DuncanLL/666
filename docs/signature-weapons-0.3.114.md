# 专武与握持校准 0.3.113–0.3.114

框架 0.3.113 接入翡图萨「因果律理」、克莱妲「切尔诺伯格」和埃芙「AN-94」。角色页右下角的武器卡进入共用 70 抽保底的专武池。已解锁的专武可在丢失或死亡后补领，随身有同款时保留原件。握持校准随存档，按模型和物品完整类型保存，枪械、刀具及其他持物走同一入口。

两把步枪的伤害与射速取原版 M16 基准，默认全自动，可切单发。原版使用现有 5.56 补给，EFZ 启用后使用 5.45 弹药与各自弹匣。固定外观和专武数值由角色包管理。因果律理沿用原版武士刀动作和音效，配高耐久与满锋利度。

| 类别 | 试听位置与原游样本 |

| 冲锋枪和芙洛伦手枪 | 完整消音 45 秒，Revolver 消音组，AWB 77 |
| 秋桦、破坏者的霰弹枪 | Auto 消音组，AWB 51 |

后续专武以现实原型的枪型、口径、射击模式和相对射速为参考，优先对照 EFZ 的同口径、同枪型、同射击模式武器，单发伤害保持同档。射速、射程和后坐恢复按原型及 PZ／EFZ 同类装备校准。批量接入时逐把登记对照枪、数值和素材来源。枪声按上表选择。声音传播与引尸参数按各枪类的消音配置核定，手枪可复用冲锋枪音色，传播范围按手枪设置。近战沿用原版对应长刀音效。

克莱妲和埃芙角色包的 0.3.114 候选使用 7.51 秒同组的不同消音变体。切尔诺伯格的引尸范围与音量脚本值为 30 / 12，埃芙按本机 EFZ 标准消音的范围 0.30 倍、音量 0.45 倍设置为 45 / 16。两把枪的听感传播分别按 35 和 45 的声音事件距离配置。声音事件与引尸数值各自独立。

本次一并收录玛绮朵 0.3.114「花影重」已安装修正的配套模型、控制和渲染资源指纹。模型、贴图和音频从外置资源读回，Git 保存源码和指纹。
