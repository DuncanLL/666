# R116 0.3.51 工坊上传准备

本次作者目录对应 Project Zomboid 42.22.2 和 Steam 工坊 Viewpoint 0.1.6.2。R116 本体为工坊项目 3834454638，同一个 MOD 提供人物运行时及 Native、Eclipse 两套光影。角色包各用独立项目，并依赖 R116 本体。

- 原版视角、Viewpoint 和 3D 人物预览共用玩家外观。原版和预览在支持的设备上自动使用 GPU 变形。Viewpoint 使用 GPU 打包网格，蒙皮和插值由 CPU 完成。
- Native 云反射使用 Viewpoint 的纹理槽位。启用云反射时，修复了部分角色身体发黑。
- 黛烟、可露凯和索米使用对应皮肤的官方头像。可露凯的独立角色包使用匹配 PMX UV 的身体贴图，并分离镜像 UV 两侧的切线。
