# 局部体积软体预览 V3 调校

妮基塔 V2、V3 滑块与克莱妲视觉已获用户认可。公共 C ABI 已移入 `native/chest-softbody/softbody.cpp`，0.3.0 接入游戏试装，见 `docs/chest-softbody-trial.md`；本目录保留独立预览检查工具，不自动安装或发布，也不代表游戏或所有 PMX 已验收。

## 调校

新增柔软程度、回弹阻尼、惯性重量、效果幅度四项，均为相对 0–100 的调校量，不是生理测量单位。默认分别显示约 45、12、50、100，保留已认可 V2 的实际物理默认值 `.45/.045/1/1`。540 帧、9772 个区域顶点的完整位移与法线输出 SHA 均与 V2 相同。

软硬和阻尼复用已有材料参数；重量按当前模型原有质量乘以 0.6–1.4，并更新 Bullet 的逆质量缓存，保持固定点质量为零。只在调整时更新，不重建人物、软体会话或提高频率。幅度控制显示形变的 0–100%，零值保持原模型位置。

工作台工程保存并恢复这四项设置。相应界面与本机人物历史不提交仓库。旧版预览仍在原目录和原入口，新滑块版位于独立目录，未替换运行中的 DLL。

两人物在两类真实舞蹈下验证了默认值、各参数两端和代表性极端组合。更低阻尼曾触发局部翻折，故当前可选阻尼限定在已验证的 `.035–.12` 范围；这不是把已失败组合标为通过。

## 实现

复用固定 Bullet 版本 `63c4d67e337017f9d8b298c900e9aabdb69296e7` 的 `btDeformableNeoHookeanForce`、隐式时间积分、弹性阻尼和重心插值。V1 的壳面/径向弹簧改为实际四面体体积弹性，形状剪切与体积阻力分开。上游文件的两处固定点修正及独立接入边界见 `provenance/bullet-softbody-preview.md`。

原 PMX 骨骼和蒙皮权重确定局部区域，几何确定尺寸，没有人物名、骨号、舞蹈或物品特判。每侧 44 个模拟点通过上游四面体插值带动原网格和衣料权重，更新同一形变梯度对应的法线，不改原 UV、拓扑或作者模型。内部体积中心和附着区域由动画驱动。

坐标与 MC-MMD loader 一致，只反射一次 Z。`unit_scale` 是 PMX 单位与游戏动作骨架单位的比值，不是经过人体测量的 SI 标定。静止形状以作者原模型为参考，当前不额外施加静态重力下垂。

同一区域不叠加旧胸骨物理和新软体。工作副本仅调整对应刚体的驱动方式，其他作者刚体/关节保留；原 PMX、旧骨骼方案、普通工作台和游戏安装不覆盖。工作台适配器及 UI 不进入 Git。

## 数值与可见效果

外部检查使用 60Hz 姿态输入；局部体积内部最多 1/240 秒一步。固定点插值，维护隐式积分的当前/历史速度，阻尼和人工脉冲不会被历史缓存覆盖。蒙皮 MaxDistance 约束将自由度限制在原形状附近，避免动画大幅运动把局部体积拉散；这不等于真实身体/衣料接触。

对真实 True Actions Running Man、左右 Salsa 及动作退出共 780 帧检查了默认值和滑块两端；数值证据在本地 `build/softbody/dance-response.json`，实际同输入新旧渲染在 `dance-visual-comparison.json` 和对照动图。稳定性、可见差异与用户认可分开，不以非零顶点位移冒充视觉通过。

当前仍有体积误差及较强人工冲击后的回形残差，未满足完整恢复阈值，不能标为完整验收通过。未实现身体、手或衣物碰撞，未测游戏 FPS、多人或所有模型。新的体积求解明显重于原骨骼方案；本阶段交付可比较的预览，不承诺轻量游戏版本。
