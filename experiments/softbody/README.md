# 局部软体体积形变预览

这是一条独立实验分支，不是当前游戏运行方案，也未接入游戏安装或工坊发布脚本。当前只以妮基塔验证，不能声称所有 PMX 通用验收完成。

## 复用与适配

- 直接编译本仓库固定 Bullet 版本 `63c4d67e337017f9d8b298c900e9aabdb69296e7` 的 SoftBody 源码，不修改求解器，不导入 PZMMD 作者实现。
- 用原 PMX 骨骼名称和实际蒙皮权重确定局部区域；尺寸来自有效权重区域几何，附着方向来自原骨位置，质量随有效体积变化，不用角色 ID 或固定小球半径。
- 坐标约定与现有 MC-MMD loader 一致，只在导入时反射一次 Z；PMX 到源骨架坐标使用现有 `unit_scale` 的倒数。没有把这个比值误写成生理单位。
- 每侧约 100 个模拟点，表面弯曲约束、中心径向链接、体积力和形状恢复都由 Bullet 执行。使用中心四面体和 Bullet 自带重心插值把局部变形传给原皮肤与相关权重衣料。
- 四面体用于绑定和法线变换，这里没有宣称已接 FEM 连续体求解。法线按相同局部变形梯度更新，原网格、UV、拓扑及静止法线保持。
- 不允许同一区域叠加旧胸骨物理与新软体：实验工作副本只把相应刚体改为动画所有，其他作者刚体/关节保留。原 PMX 及旧预览保持只读。

## 数值策略与边界

外部动作仍按原 60Hz 检查；只有局部软体细分到最多 1/240 秒内部步长，插值附着姿态，并按时间步换算阻尼和形状恢复。现用头发、衣物、游戏核心未改变。不得把这种内部细分隐瞒为没有增加计算。

初始化完成后固定完整静止约束，避免下一帧只移动附着点后重新捕获错误静止长度。直接采用 Bullet 位置求解预设；不启用会覆盖其预测回形修正的速度迭代。

默认稳健参数下，420 帧妮基塔站走跑停的体积约 97.2%–100.2%；固定姿态继续运行可恢复到原轮廓附近。更软参数的瞬时体积误差明显增大，预览需直接显示，不能宣传严格体积守恒。当前日常动作的局部形变较细，视觉是否值得仍由用户比较，不以“非零形变”代替视觉认可。

预览的局部按压按钮是人工速度脉冲，仅用于查看回弹；未实现真实身体/衣物/手部碰撞，也未安装游戏或测量游戏 FPS。

## 构建与检查

```powershell
python experiments/softbody/build_preview.py
python experiments/softbody/check_solver.py
```

复用 `.local/paths.json` 的私有工具链和已验证 Bullet 静态库，输出 `build/softbody/AimohSoftBodyPreview.dll`。工作台适配器、其界面代码、模型、图片和对照 GIF 留在本机，不提交本仓库。源码接入游戏前需要新的生命周期、形变与渲染回归。
